# Session 03) Feature Engineering
This `Jupyter Notebook` contains the hands-on coding exercises for Feature Engineering. In this notebook, walk through the data preparation pipeline—handling missing values and capping outliers—before applying the 4-step feature engineering framework to the SF24 dataset. You will engineer interaction features (THI), ratio features (N:P), and encode categorical variables.

You can run this `notebook` locally using `Jupyter`, or upload it directly to Google Colab. (Please refer to the dataset README for full variable descriptions).
